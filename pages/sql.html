Conceptos clave para consultas de bases de datos.

Introducción a SQL

SQL (Structured Query Language) es un lenguaje estándar para gestionar bases de datos relacionales. Permite consultar, insertar, actualizar y eliminar datos.

Consultas SELECT

La consulta básica: SELECT columna FROM tabla WHERE condición;

JOINs

Unir tablas: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN.

Funciones Agregadas

COUNT, SUM, AVG, MIN, MAX para análisis de datos.
